# Finsen Notes — ColourNote 替代品

一個純網頁（PWA）嘅彩色筆記 app，冇後端、冇帳號，資料淨係存喺你部裝置嘅瀏覽器入面。

## 功能

- **彩色筆記 + Checklist**：每則筆記可以揀 10 隻顏色，並且喺「純文字」同「Checklist」兩種模式之間切換
- **資料夾分類 + 搜尋**：自訂資料夾、上面 chip 篩選，搜尋列即時搵標題／內容／checklist 項目
- **到期日／提醒**：每則筆記可設到期日（連時間），逾期／今日到期會用顏色標記；App 開住嘅時候會嘗試發本機通知
- **釘選**：重要筆記可以釘喺最上面
- **備份／還原**：一鍵匯出全部資料做一個 JSON 檔，隨時匯入還原或者過機

## 資料存喺邊

全部資料存喺瀏覽器嘅 `localStorage`，即係**淨係喺嗰個瀏覽器、嗰部裝置度**，唔會自動同步去第二部機或者第二個瀏覽器。跨機／跨瀏覽器要用「備份」匯出 JSON，再喺另一邊「還原」匯入。

建議：安裝落手機主畫面之後，記得定期備份一次，並將備份檔存喺你自己揀嘅資料夾（例如 Google Drive / Downloads），以防換機或者清瀏覽器資料時甩失。

## 點樣喺手機用

呢個 app 係純靜態網頁（`index.html` / `styles.css` / `app.js`），要用手機瀏覽器打開先用得，而且要透過 **http(s)** 網址先可以完整安裝做 PWA（用 `file://` 直接開會冇晒 Service Worker／離線快取，部分手機仲會唔畀用 localStorage）。三個做法揀一個：

### 方法一：部署去免費靜態網站（最簡單，跨機都用到）
將呢個資料夾（`30 - Projects/NotesApp`）推上 GitHub，再用 **GitHub Pages** 或者 **Netlify / Vercel** 一鍵部署，攞到一個 `https://` 網址。手機瀏覽器開嗰個網址，Chrome 會提示「新增至主畫面」，裝咗就同 app 一樣用。

### 方法二：手機自己起本機伺服器
Android 用 Termux 之類嘅 app 開個 `python -m http.server` 或者 `npx serve` 指向呢個資料夾，然後瀏覽器開 `http://localhost:port/`。

### 方法三：直接用瀏覽器開檔案（將就用）
直接喺手機瀏覽器打開 `index.html`。基本筆記功能（新增/編輯/顏色/checklist/資料夾/搜尋/備份還原）多數都用到，但唔可以安裝做主畫面 app，離線快取／部分裝置嘅本機儲存都可能唔穩定。

## 提醒通知嘅限制

手機瀏覽器嘅背景執行有好多限制（尤其 iOS Safari／PWA），呢個 app 冇後端伺服器推送通知嘅能力，所以：

- 通知淨係喺 App 開住（前台或者啱啱切去背景）先有機會觸發
- 就算冇開通知權限，逾期／今日到期嘅筆記一律會用顏色標記（紅色=逾期，橙色=今日），呢個先係最可靠嘅提醒方式
- 要啟用通知，去右上角「⋮」→ 設定 → 「啟用通知」
